## What this means for the build plan (features 4 and 5, route detail)
- Show 2–3 named route options per job, each with minutes and a toll yes/no flag. Lead with the toll-free option.
- Eric's default leans toll-free: he chose Rt 7 over the Toll Rd even though it was 5 min slower.
- Name the main road for each option ("via Rt 7", "via US-29", "via Toll Rd"). That's how Eric thinks about routes.
